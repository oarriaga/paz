# Keypoint estimation

Runs `paz.applications.DetectFaceKeypointNet2D32` on a webcam stream.

## Run

```bash
python3 demo.py
```

Options: `--camera` (default 0), `--H` (480), `--W` (640).

## Output

A video window with the webcam stream and the pipeline output.

## Requirements

A webcam; the script has no `--image` option.
